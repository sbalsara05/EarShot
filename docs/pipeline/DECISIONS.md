|---|---|---|---|
| 1 | Branch `overnight` lives in **`shourya0523/earshot-data`** (user's call): pushes to `sbalsara05/EarShot` are refused (GitHub App not connected). | 2 | Phonetic key = own Metaphone port (`core/tools/phonetic.py` ≡ `Phonetic.swift`), not Double Metaphone | pip `metaphone` package | running downloaded package code was blocked; one tiny shared algorithm keeps Python and Swift identical |
| 3 | ADPCM frame = 4-byte block header + 160 bytes (164 B payload, 171 B packet) | 160 B with no state | each frame decodes alone, so a lost frame never desyncs; 68.4 kbps |
| 4 | `seq` is a per-packet-type counter | one shared counter | audio gaps must be detectable from audio seq alone; tap seq is the ack id |
| 5 | Little-endian wire format | network order | ESP32 and Apple are LE; zero-cost |
| 6 | Unspoken unit is **never filled**. If the amount matches exactly one protocol dose, `fields.unit_suggested` carries it and outputs say "unit not heard; protocol dose is in mg" | fill + flag | "anything not heard stays blank"; matches the data agent's ground truth |

| 10 | **PII is kept by default** (user's call: the ePCR needs name/DOB/address). Scrubber stays available: `--pii-scrub` / `"pii_scrub": true` tokenizes quotes and fields; raw transcript always stays raw | scrub by default | user instruction |

| 12 | whisper.cpp linked as a system library (pkg-config), `EARSHOT_NO_WHISPER=1` to build without | vendor sources in SwiftPM | ggml build flags are complex; system lib works on Linux/macOS, xcframework on iOS |
| 13 | Greedy, temperature 0, no fallback, fixed threads | default sampling | repeatable eval |

| 15 | Whisper non-speech tags inside a segment (`[beep]`, `(siren)`) are dropped in cleanup as a logged correction; whole-segment tags are dropped before segment ids are assigned | keep | data agent finding (stock small.en emits them in siren noise) |
| 16 | Sound-alike (phonetic) drug matches need a unit, route or give-verb within 3 tokens and are always "please confirm" | number nearby | "lights", "General" falsely matched in golden test |

| 18 | Board firmware (VoiceS3R, Feather) removed at user request; only `firmware/common` (wire format, ADPCM, consent state machine, tap detection) kept, with host tests | keep board code | someone else owns the clip firmware |
| 19 | Rhythm names (afib, SVT…) are not extracted; ECG rhythm stays with the crew | extract as eVitals.03 | an interpretation; "afib" is a diagnosis trap in the data agent's GT |
| 20 | Procedure names follow chart usage ("BVM ventilation", "IV access", "splinting"); stroke screens are named "BE-FAST screen" / "Cincinnati scale", never "stroke scale" | GT name "stroke scale" | the GT trap list flags the word "stroke" anywhere in outputs |
| 21 | Heard times (on scene, transporting, arrival, transfer of care, back in service) use the utterance start; a tap on such an utterance labels it (tap time wins) | word-time estimate | matches how crews and the GT time-stamp events |
| 22 | Oxygen given by device ("non-rebreather at 15") is a medication with route NRB/NC (NEMSIS route codes 9927031/9927025) | no event | GT and NEMSIS both treat O2 as a medication |
| 23 | Prompt is format-only: physically impossible values that never appear in test/dev calls and fall outside the extractor's ranges; doses carry units, not amounts. A prompt-copy check is part of the ship rule, and models are compared with no prompt too | measured seed prompt with realistic values | owner: a realistic prompt can prime the very values being scored |
| 24 | Taps come from the clip button only. Knock/snap detection was removed (firmware/common detector, contract FW-T5/T6, tuning write); wire sources 1/2 are retired and rejected. Speech still labels button presses | keep acoustic taps | owner decision |
| 25 | Whisper segments from one VAD chunk are joined when a segment does not end a sentence (`ASRPiece.joinUnfinished`, batch and live). Text is Whisper's, unchanged; token times kept; hallucinations dropped first; never across chunks | join in cleanup across raw segments | Whisper split "blood pressure is 150 over" / "90, ..." and the BP was lost (firmware e2e run); joining before raw segments exist keeps one raw span per reading, so receipts stay simple |
| 26 | A clock time after "at" is one `HH:MM` token in cleanup (rule `time:clock`, logged): "at 1410", "at 1410 hours", "at fourteen ten", "at fourteen hundred". Not when a unit follows or the value cannot be a 24-hour time; 3-digit forms ("at nine thirty" -> 930) are left alone | add "at" to the not-a-dose list | "Aspirin given at fourteen ten" was charted as a 14 (or 1410) dose; "at" also precedes real amounts ("running at 125 ml"), so only the time form is changed |
| 27 | The optional Phi-3.5-mini passes (recovery, narrative) live in `sbalsara05/EarShot` on `pipeline` (owner's call), not in earshot-data, whose brief they were first written against | earshot-data `overnight` | owner: pipeline work happens here |
| 28 | Model: Phi-3.5-mini-instruct GGUF, bartowski's quantization of `microsoft/Phi-3.5-mini-instruct` (MIT). Q4_K_M default: `https://huggingface.co/bartowski/Phi-3.5-mini-instruct-GGUF/resolve/main/Phi-3.5-mini-instruct-Q4_K_M.gguf`, 2,393,232,672 B, sha256 `e4165e3a71af97f1b4820da61079826d8752a2088e313af0c7d346796c38eff5`. IQ4_XS low-memory: same path `…-IQ4_XS.gguf`, 2,059,853,088 B, sha256 `bc4e2d58ea331ffded51fc237874306df2a711209ab0ec91dd57b49dfdb6e36a`. Q8_0 reference: `…-Q8_0.gguf`, 4,061,222,688 B, sha256 `76fbf02f6fe92af57dbd818409bc8a0240026f1f3609bb405c3be94c973fb823`. `core/scripts/fetch_phi.sh` downloads to `models/` (git-ignored) and checks the hash | other GGUF uploads | widely used quantizer; the sizes match the brief; hashes pinned |
| 29 | llama.cpp pinned to release `v1.0.0` = commit `b1b770d90d94cad9e9ea5b993bdbc383a522fb28` (Linux: built by `setup_linux.sh`; macOS: Homebrew's `llama.cpp 1.0.0`, same commit; iOS: `build-xcframework.sh` at the tag). Only `libllama` is built (`LLAMA_BUILD_APP/COMMON/TOOLS=OFF`), with clang (v1.0.0 passes clang-only warning flags) | HEAD | repeatable builds |
| 30 | One ggml per process: llama.cpp and whisper.cpp both bundle ggml, and two copies clash. Linux: llama.cpp installs ggml, then whisper.cpp builds on it (`WHISPER_USE_SYSTEM_GGML`, found as a CMake package: llama.cpp installs no `ggml.pc`). macOS: Homebrew already shares its `ggml` formula, but its `llama.pc` omits it, so `core/scripts/setup_macos.sh` writes a `llama.pc` that `Requires: ggml` into `core/.pkgconfig`. iOS: each xcframework is a dynamic library with its own ggml; Apple's two-level namespace keeps them apart | whisper with its own ggml | verified on Ubuntu 24.04: `libwhisper` and `libllama` load the same `libggml-base.so.1` |
| 31 | Phi decoding: greedy (temperature 0) in Swift over llama.cpp's logits, under a GBNF grammar with the usual fast path (the top token is checked against the grammar first; the whole vocabulary is masked only when it fails, ~2% of tokens). CPU only (`n_gpu_layers 0`), fixed threads, fixed seed 1234 (unused by greedy), context 4096, the model's own chat template (`llama_chat_apply_template`). The system prompt's keys/values are reused between calls in a run, so two runs of the same input give the same files | llama.cpp's sampler chain; GPU | determinism; 2–3x faster generation than masking every token |
| 32 | Phi recovery may add vitals, medications, procedures and findings that the code verifier proves are in the transcript (brief rule 1), as events with `source: heard`, `models.extract = "phi-3.5-mini-q4 (verified)"`, flag `llm`, and a receipt with the quote. This is stricter than, and separate from, the app's NoteWriter rule in `docs/HYBRID.md` (vitals and allergies only, always "please confirm"), which is unchanged | apply the NoteWriter rule to Phi too | brief; the verifier checks span id, verbatim quote, value in the quote after cleanup, formulary and ranges |
| 33 | A rejected proposal becomes "heard, please confirm" (status `kind: llm_unverified`, the quote and the name of the failed check; never the model's value) only if its quote is verbatim in its span, has no diagnosis words, and holds something checkable (a number for a numeric field, or drug/procedure/finding words). Otherwise (unknown span, invented quote, diagnosis, placeholders like "not specified") it is only logged in `llm.json` | confirm everything | the medic should not review the model's inventions; nothing unproven reaches a field |
| 34 | A recovered dose, unit or route counts only beside a verified drug from the same span; dose plausibility is 0.001–5000 (the extractor has no dose range; 5000 covers mL of fluid) | accept alone | a dose without a drug is not a medication |
| 35 | Narrative checker, beyond the brief's list: "a/b" must be one cited blood pressure, systolic first (Phi swapped one in testing); a unit must have been heard (`unit_suggested` is the protocol's, rule 6); every medication and procedure must be cited (the narrative replaces the template, so it may not leave one out); advice words fail. The model's input marks a dose with no spoken unit as `unit: "not said"` (input only) | brief's list only | each was seen in testing |
| 36 | The checked Phi narrative is `eNarrative.01` on its own (XML-escaped like any value) and a cited paragraph at the top of chart.md; the rest of chart.md and every structured section stay code-written.
